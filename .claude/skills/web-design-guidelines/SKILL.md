# Web Interface Guidelines

Review files for compliance with the Web Interface Guidelines in `rules.md` next to this file.

`rules.md` is a reviewed, pinned copy of `command.md` from https://github.com/vercel-labs/web-interface-guidelines (commit `434b7f9`, MIT). Do not fetch a newer version at run time; update the pinned copy deliberately instead.

## Usage

1. Read `rules.md`.
2. Read the files the user named, or ask which files to review.
3. Check them against every rule in `rules.md`.
4. Report findings in the terse `file:line` format that `rules.md` specifies.
